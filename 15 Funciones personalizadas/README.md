En este vídeo aprenderemos a crear y utilizar funciones personalizadas en Python, una de las herramientas más importantes para escribir código reutilizable, organizado y eficiente.

Partiendo de ejemplos sencillos, veremos cómo definir nuestras propias funciones "def", cómo invocarlas y cómo modificar su comportamiento. También exploraremos el uso de parámetros y argumentos, entendiendo claramente la diferencia entre ambos conceptos. Más concretamente, veremos cómo:

✔️ Crear funciones desde cero
✔️ Pasar uno o varios argumentos
✔️ Devolver resultados con "return"
✔️ Utilizar múltiples "return" con estructuras condicionales
✔️ Entender el concepto de variables locales

Terminaremos analizando por qué las funciones son clave para mejorar la calidad y mantenibilidad de nuestros programas.

En el próximo vídeo profundizaremos en otro tipo de funciones: las funciones lambda.
